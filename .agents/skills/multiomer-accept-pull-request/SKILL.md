# multiomeR Accept Pull Request

## Workflow

1) Update the `NEWS.md` on the PR branch under the 'development version' section as appropriate for the changes indicated in the PR body, with links to the PR. The format of the `NEWS.md` file mirrors the PR body for easy integration.
2) Use standard workflow to fast-forward merge the pull request into the main branch. Do not squash or rebase.
