For molecular analyses, GEX and ATAC counts of the final WNN nuclei are summed within each donor–annotation-class combination to form pseudobulk samples. Four feature matrices are tested:

- **Gene expression** (differential gene expression, DGE): gene pseudobulk counts.
- **Chromatin accessibility** (differential chromatin accessibility, DCA): consensus-peak pseudobulk counts.
- **Motif-family accessibility** (differential transcription-factor motif accessibility, DTFA): betterChromVAR bias-corrected deviations of the 233 JASPAR motif families, calculated from the pseudobulk ATAC counts [@germain2026_betterchromvar]. This matrix is therefore continuous. Unlike chromVAR *z*-scores, deviations do not grow with sample depth, and no per-sample centering or cross-sample normalization is applied.
- **Transcription-factor activity** (differential CollecTRI transcription-factor activity, DCTA): signed CollecTRI regulator activities, inferred with the `decoupleR` univariate linear model from filtered, library-size-normalized log-CPM GEX pseudobulks [@muller_dott2023_collectri; @badia2022_decoupler]. Each regulator requires at least five measured targets. The CollecTRI network is used only when its checksum matches the recorded one, and complexes such as AP1 and NF-κB are kept as single regulons.

For each model, donors that miss a model variable or fall outside an optional donor list are removed. Samples outside an optional annotation-class subset are also removed, and the DTFA analysis by default removes samples with fewer than 5,000 ATAC counts. For count matrices, zero-depth samples are removed, features are filtered with the design-aware `edgeR::filterByExpr()`, and library sizes are normalized with `edgeR::normLibSizes()` [@robinson2009_edger].

Model matrices are built from a configured formula or custom design function, and contrasts from named linear expressions or custom contrast functions. A configured random effect selects `limma::duplicateCorrelation()` with the random effect as block [@ritchie2015_limma]. For counts, voom precision weights are re-estimated for the block and correlation (`edgeR::voomLmFit()`). Wherever an intra-block correlation is estimated, the consensus is taken from at most 50,000 evenly spaced features, as limma's author recommends for large feature sets. The models are still fitted to all features. Without a random effect, count designs with more than one coefficient are fitted with edgeR quasi-likelihood models and tested with quasi-likelihood F-tests. These models use robust empirical Bayes moderation of the dispersions. Continuous matrices and single-coefficient designs use limma. A single-coefficient count design is fitted on the raw counts, without the filtering and normalization above. An optional paired-cell-type route fits each annotation class separately with voom–limma, or limma for continuous matrices. It allows at most one pseudobulk per pairing unit and class. A cross-class contrast is tested on a combined response, restricted to the donors present in every class involved. This response is the contrast-weighted sum of the classes' log-expression. It is weighted by the inverse of its variance, which is computed from the classes' precision weights. The combined response is fitted with the same donor-level design and correlation block, so each feature has its own covariance between classes.

For each model and contrast, Benjamini–Hochberg FDR is calculated across the tested features, and features with an FDR below 0.05 are significant. DGE contrasts are also tested against the MSigDB Hallmark and Reactome collections with competitive `camera` tests [@wu2012_camera; @dolgalev2026_msigdbr]. These tests use the contrast's expression, precision weights and design, or the combined response for cross-class contrasts. Each set's inter-gene correlation is estimated from the residuals, and each set needs at least ten tested genes. FDR is calculated within each contrast and collection. A cross-modality comparison maps CollecTRI regulators to JASPAR families. It compares the model *t*-statistics, rather than the raw scales, of transcription-factor activity and motif-family accessibility. Where gene expression is fitted with limma, it also compares TF expression (edgeR tests report no *t*-statistic). Family-level summaries use the median regulator *t*-statistic. An analysis stops with an error rather than returning a model when no samples or testable features remain or residual degrees of freedom are below one. It also fails when a correlation block or contrast is invalid, or when too few shared donors remain for a requested paired-cell-type comparison.
