Harmony correction, with at most 25 iterations and `lambda = 1`, can be applied separately to the selected GEX principal components and ATAC LSI dimensions but is off by default [@korsunsky2019_harmony; @patikas2026_harmony2]. The configured metadata columns, to which the ATAC correction can add its own, are combined into one interaction batch factor, and nuclei with missing covariate values are removed with a warning.

For each modality, approximate nearest neighbors are found on the selected dimensions with BPCells hierarchical navigable small world (HNSW) search [@malkov2020_hnsw] using cosine distance, converted to a shared-nearest-neighbor (SNN) graph with Jaccard weights, pruning weights below 1/15, and clustered with the modularity objective of the Leiden algorithm in ten iterations [@parks2025_bpcells; @traag2019_leiden]. Clusters are renumbered by size, and clusters of fewer than 100 nuclei by default are removed from the GEX, ATAC and WNN partitions. UMAP embeddings are computed with uwot using cosine distance on separately configurable dimensions, by default the clustering dimensions [@melville2026_uwot].
