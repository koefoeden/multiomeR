Annotation-class pseudobulk deviations are calculated separately rather than by averaging the nucleus-level results. ATAC counts are summed by the final WNN cell-type labels, which the other analyses also use. A betterChromVAR background model is fitted to the resulting peak-by-class matrix. The expected accessibility of each peak averages the depth-normalized class profiles with equal weight. Each class is thus compared with the average class rather than with a reference dominated by the most abundant classes. Background peaks are matched on this expectation and on GC and fragment-length bias. The deviation is the accessibility of the weighted peaks minus that of the matched background peaks, relative to their expected accessibility. It thus corresponds to chromVAR's bias-corrected deviation. A relative deviation also standardizes the deviations across annotation classes within each trait. Analytic z-scores, rescaled for the peak weights as for nuclei, give one-sided P-values. Their null variance is the variance of the counts of the matched background peaks around their expected accessibility. betterChromVAR 1.1.10 overestimates this variance for deep counts such as pseudobulks, so it is recomputed from the counts. Benjamini–Hochberg-adjusted P-values across all traits and annotation classes are reported, and heatmaps mark classes at q < 0.05. Locus-contribution plots mark unadjusted z-scores of at least 1.645 and 2.326. When effect sizes are available, an absolute-effect version weights variants by posterior probability times absolute effect size. When only loci carry effects, each locus's lead-variant effect is used. These weights are rescaled to sum to the kept variants' posterior probabilities. Each class deviation is split into additive contributions from its loci and variants, which sum to the class totals. The loci and variants are labeled with the highest-scoring Open Targets locus-to-gene genes [@mountjoy2021_l2g]. Detail plots are drawn for classes with a positive deviation and a z-score of at least 1 by default, in either weighting. They show the top loci by absolute contribution and by combined contribution and effect-size rank.

Each trait's top set holds the class with the largest deviation and every class not significantly below it. Credible sets whose lead variants in peaks lie within 500 kb of each other form one locus. In 1,000 bootstrap samples of these loci, the sampled loci's contributions are summed for each class. Each class keeps the background expectation and denominator of all loci, so the samples approximate rather than repeat the analysis. They give the standard error of each class's shortfall from the top class. A class is excluded when a one-sided normal test of its shortfall reaches P < 0.05 divided by the number of other classes. By the Bonferroni inequality, the top set then contains the class with the largest true deviation with at least 95% probability. Traits with fewer than 10 loci get no top set, because so few loci give no reliable bootstrap. Heatmaps outline the top set for traits whose top class reaches q < 0.05.
