7  Configuration and inputs

7.1 cfg_datasets.yaml

Dataset-level settings live in cfg_datasets.yaml. A dataset is the shared context for one or more 10x reactions, typically a genome/reference combination plus dataset-wide QC rules. Reactions in cfg_reactions.tsv refer to these dataset keys, so define datasets before adding reaction rows.

Typical dataset-level settings include:

  • dataset_cellranger_arc_refdata_dir: Cell Ranger ARC reference directory for the dataset genome.
  • dataset_QC_exclude_list_per_reaction: reaction-level QC filters applied before aggregation.

The public PBMC example uses the following dataset entry, rendered directly from cfg_datasets.yaml:

Show immune_human_dataset 
YAML
immune_human_dataset:
  mandatory:
    dataset_cellranger_arc_refdata_dir: example_data/refdata-cellranger-arc-GRCh38-2020-A-2.0.0
  optional:
    dataset_QC_exclude_list_per_reaction:
      - TSS.enrichment < 4
      - nucleosome_signal > 4
      - nCount_RNA < 250
      - RNA_mito_percent > 10
    dataset_run_amulet: false

7.2 cfg_reactions.tsv

Reaction-level configuration lives in cfg_reactions.tsv. Add one row per 10x reaction with a stable reaction_ID, the matching dataset, the reaction_cellranger_count_dir, and any donor demultiplexing fields relevant to that reaction.

Each reaction should point to a cellranger-arc count output directory. The pipeline expects the configured reaction_cellranger_count_dir to contain the standard outs/ files, including:

The reaction table columns are:

Column Meaning
reaction_ID Stable reaction identifier used throughout target names and downstream config.
dataset Dataset key used to join dataset-level settings from cfg_datasets.yaml.
reaction_donor_id Donor ID assigned to all nuclei in a non-multiplexed reaction. Use NA for multiplexed reactions.
reaction_n_donors Number of donors expected in the reaction.
reaction_cellranger_count_dir Path to the cellranger-arc count output directory.
reaction_cellbender_h5_file Optional CellBender-corrected GEX H5 file. Use NA when not used.
reaction_donors_VCF_file Optional VCF for donor demultiplexing. Use NA when not used.

7.3 cfg_aggregations.yaml

Aggregation-level settings live in cfg_aggregations.yaml. An aggregation combines one or more configured reactions and controls merged RNA/ATAC processing, clustering, annotation, plotting, and optional downstream modules.

At minimum, each aggregation needs:

Field Meaning
aggregation_reaction_IDs Reaction IDs from cfg_reactions.tsv to include in the joint analysis.
aggregation_GEX_marker_genes Named marker-gene lists used for module scoring and cluster annotation.
aggregation_donor_id_metadata_tsv Donor-level metadata table with a donor_id column.
aggregation_reaction_ID_metadata_tsv Reaction-level metadata table with a TENX_reaction_ID column.

Optional aggregation settings control QC filters, RNA and ATAC dimensions, clustering resolution, UMAP parameters, subgroup analysis, plotting variables, track export, and enabled modules. YAML entries are divided into mandatory parameters that must be set and optional parameters that are usually inherited from default unless the entry overrides them. NULL values intentionally disable optional behavior.

Each aggregation also points to metadata files:

  • aggregation_donor_id_metadata_tsv: donor-level metadata with a donor_id column matching the donor IDs assigned during per-reaction processing.
  • aggregation_reaction_ID_metadata_tsv: reaction-level metadata with a TENX_reaction_ID column matching the configured reaction IDs.

These metadata tables are joined to the per-cell metadata before downstream correction, plotting, and modelling.

The public PBMC aggregation below is rendered directly from cfg_aggregations.yaml. It shows the required aggregation inputs plus the example-specific optional overrides; standard optional settings are inherited from default.

Show immune_human_2x 
YAML
immune_human_2x:
  mandatory:
    aggregation_donor_id_metadata_tsv: example_data/immune_human_dataset_donor_id_metadata.tsv
    aggregation_reaction_ID_metadata_tsv: example_data/immune_human_dataset_reaction_id_metadata.tsv
    aggregation_reaction_IDs: [healthy_PBMC_human, lymphoma_lymph_human]
    aggregation_GEX_marker_genes:
      T: [CD3D, CD3E, CD4, CD8A, CD8B]
      NK: [KLRD1, KLRC1, KLRF1, NKG7, GNLY]
      Mono: [CD14, FCGR3A, LYZ, S100A8, S100A9]
      B: [CD79A, CD79B, MS4A1, CD19]
      pDC: [CLEC4C, TCF4, IRF7, IL3RA]
      Plasma: [XBP1, MZB1, PRDM1, JCHAIN]

    modules: [differential_analyses, genetic_enrichment]
    aggregation_categorical_vars: [condition, tissue, cell_sorting, instrument, target_recovery]
    aggregation_QC_exclude_list_combined_object:
      - nCount_ATAC < 1000

      - atac_peak_counts_blacklist_frac > 0.01
    aggregation_ATAC_marker_TFs:
      T: [BCL11B, TCF7, LEF1, RUNX3]
      NK: [EOMES, TBX21, NFIL3]
      Mono: [SPI1, IRF8, CEBPA, CEBPB]
