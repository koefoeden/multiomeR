For molecular analyses, GEX and ATAC counts are summed within each donor–annotation-class combination to form pseudobulk samples, the same pseudobulks used for the Seurat/Signac export. Four feature matrices are tested:

- **Gene expression (DGE):** gene pseudobulk counts.
- **Chromatin accessibility (DCA):** consensus-peak pseudobulk counts after peak-level quality control.
- **Motif-family accessibility (DTFA):** betterChromVAR bias-corrected deviations of the 233 JASPAR motif families calculated from the pseudobulk ATAC counts, so this matrix is continuous; deviations, unlike chromVAR *z*-scores, do not grow with sample depth, and no per-sample centering or cross-sample normalization is applied [@germain2026_betterchromvar].
- **Transcription-factor activity (DCTA):** signed CollecTRI regulator activities inferred with the `decoupleR` univariate linear model from filtered, library-size-normalized log-CPM GEX pseudobulks, requiring at least five measured targets per regulator [@muller_dott2023_collectri; @badia2022_decoupler]. The CollecTRI network is accepted only when it matches a pinned checksum, and complexes such as AP1 and NF-κB remain intact as regulons.

For each model, donors missing a model variable or outside an optional donor list and samples outside an optional annotation-class subset are removed; the DTFA branch additionally removes samples below a configured minimum ATAC depth. For count matrices, zero-depth samples are removed, features are filtered with the design-aware `edgeR::filterByExpr()`, and library sizes are normalized with `edgeR::normLibSizes()` [@robinson2009_edger].

Model matrices are generated from a configured formula or custom design function, and contrasts from named linear expressions or custom contrast functions. A configured random effect selects voom for counts followed by `limma::duplicateCorrelation()` with the random effect as block [@ritchie2015_limma]. Wherever an intra-block correlation is estimated, the consensus is taken from at most 50,000 evenly spaced features, while the models are fitted to all features. Otherwise, count designs with more than one coefficient use edgeR quasi-likelihood dispersion estimation with robust fitting and testing, and continuous matrices and single-coefficient designs use limma; a single-coefficient count design is fitted on the raw counts without the filtering and normalization above. An optional paired-cell-type route fits each annotation class separately and permits at most one pseudobulk per pairing unit and class. A cross-class contrast is tested on its combined response: for the donors present in every class involved, the contrast-weighted sum of the classes' log-expression, weighted by the inverse of its variance from the classes' precision weights, is fitted with the same donor-level design and correlation block, so each feature has its own covariance between classes.

For each model and contrast, Benjamini–Hochberg FDR is calculated across the tested features, and features with an FDR below 0.05 are significant. DGE contrasts are also tested against the MSigDB Hallmark and Reactome collections using competitive `camera` tests on the contrast's expression, precision weights and design, with each set's inter-gene correlation estimated from the residuals and at least ten tested genes per set [@wu2012_camera; @dolgalev2026_msigdbr]; cross-class contrasts use their combined response. FDR is calculated within each contrast and collection. A cross-modality comparison maps CollecTRI regulators to JASPAR families and compares the model *t*-statistics of transcription-factor activity, motif-family accessibility and TF expression rather than their raw scales; family-level summaries use the median regulator *t*-statistic.

Diagnostic outputs report pseudobulk depth, retained sample and donor counts, paired-donor support, P-value distributions, effect directions and significant-feature counts. When a trait identifier is configured, the top DGE features are annotated with Open Targets evidence. A branch fails rather than returning a model when no samples or testable features remain, residual degrees of freedom are below one, a correlation block or contrast is invalid, or too few shared donors remain for a requested paired-cell-type comparison.
